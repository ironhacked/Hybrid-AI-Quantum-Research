## 🔭 OVERVIEW

The ultimate goal of this project is to develop a **general-purpose Hybrid Classical–Quantum Machine Learning Framework** that explores the integration of classical artificial intelligence and quantum computing.

The project aims to go beyond simply combining classical and quantum algorithms. It seeks to understand how both computational paradigms can interact, exchange information, contribute to a common learning process, and influence the final output.

The framework will be developed progressively, beginning with the mathematical and computational foundations of classical machine learning and quantum computing, followed by the independent implementation and experimentation of their respective algorithms.

Once these foundations are established, the focus will shift towards designing, implementing and evaluating hybrid architectures. Their performance will be compared against classical approaches to investigate potential advantages, limitations, computational costs and practical challenges.

> **Long-term research direction:** Exploring the application of hybrid AI–quantum computing in scientific and biomedical research, particularly cancer-related research.

---

## 🎯 OBJECTIVES

There are three major objectives behind this project.

### ① Understand Machine Learning

Understand Machine Learning right down to its core: the ideas behind individual algorithms, the mathematics involved, and the code behind the libraries I use, rather than treating them as mere tools in the process.

### ② Understand Quantum Computing

Understand the fundamentals of Quantum Computing, including the physics and mathematics involved and the physical and mathematical foundations of qubits, gates, circuits and quantum algorithms.

### ③ Understand the Intersection

Understand how two computational systems based on fundamentally different hardware paradigms can interact.

Investigate how they can complement or limit each other, how information is exchanged between them, and how their combined operation affects the final output.

## 🔬 RESEARCH DIRECTION

The project follows an **implementation-driven and experimental approach**.

Rather than relying entirely on existing libraries and pre-built algorithms, the primary focus is on understanding and implementing the underlying mathematical and computational processes wherever practical.

Experiments will investigate:

| Research Parameter | What will be examined |
|---|---|
| 🎯 Accuracy | Learning and prediction performance |
| ⚙️ Optimization | Convergence and parameter updates |
| ⏱️ Computational Cost | Time and computational resources |
| 📈 Scalability | Behaviour as problem size increases |
| 🛡️ Robustness | Sensitivity to noise and disturbances |
| ⚖️ Comparison | Hybrid models versus classical baselines |

**An important principle:** Quantum advantage will not be assumed. It must be investigated through appropriate experiments and comparisons.

## 🚀 GETTING STARTED

### 1. Clone the Repository

```bash
git clone <REPOSITORY-URL>
```

### 2. Navigate to the Project Directory

```bash
cd <REPOSITORY-DIRECTORY>
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it on Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

Once the dependency list is maintained in `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 5. Run an Implementation

For example, the initial linear regression implementation:

```bash
python 01-Classical-ML/01-Linear-Regression/Linear_Regression_GD.py
```

## 🧠 DEVELOPMENT PHILOSOPHY

The project follows five fundamental principles:

1. **Understand before implementing:** Mathematical and physical concepts should be understood before being translated into code.
2. **Build from fundamentals:** Implement algorithms independently wherever practical.
3. **Experiment and observe:** Test implementations, analyse their behaviour and document unexpected results.
4. **Compare objectively:** Evaluate hybrid approaches against suitable classical baselines.
5. **Document the process:** Record mathematical derivations, hypotheses, experiments, observations and limitations.
